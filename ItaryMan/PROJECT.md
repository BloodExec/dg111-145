## 🔁 Flow การทำงาน (Flowchart)

> แก้ไข diagram ด้านล่างให้ตรงกับงานของกลุ่ม (เขียนด้วย Mermaid — ดูผลได้ใน VS Code / GitHub) หรือวาดด้วยเครื่องมืออื่นแล้วแนบรูป

```mermaid
flowchart TD
    A([Start]) --> B[ตั้งค่าเริ่มต้น]
    B --> C{กดปุ่ม Quit?}
    C -- ใช่ --> Z([End])
    C -- ไม่ --> D[อ่าน Input]
    D --> E{State ตอนนี้?}
    E -- TITLE --> F{Input ถูกต้อง?}
    F -- ใช่ --> G[เริ่มเกม → PLAYING]
    F -- ไม่ --> H[แสดงข้อความเตือน]
    E -- PLAYING --> I[อัปเดตเกม: เดิน / เก็บของ / นับเวลา]
    I --> J{หมดเวลา?}
    J -- ใช่ --> K[→ GAME_OVER]
    E -- GAME_OVER --> L{กด Enter?}
    L -- ใช่ --> M[→ TITLE]
    G & H & J & K & L & M --> N[วาดหน้าจอ]
    N --> C
```

**State ของโปรแกรม:**

```mermaid
stateDiagram-v2
    [*] --> TITLE
    TITLE --> PLAYING : [เงื่อนไข]
    PLAYING --> GAME_OVER : [เงื่อนไข]
    GAME_OVER --> TITLE : [เงื่อนไข]
```
